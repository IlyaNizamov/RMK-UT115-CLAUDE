# RMK-UT115-CLAUDE — подбор цветов картинками в РМК «1С:Управление торговлей 11.5»

Расширение конфигурации **«ЦветочнаяКасса»** для «1С:Управление торговлей» 11.5: рабочее
место кассира небольшого цветочного магазина с выбором товара плитками-картинками —
группа → товар → строка чека. Чек, оплату, пробитие на ККТ и смену ведут типовые механизмы
РМК и библиотеки подключаемого оборудования (БПО); расширение добавляет только выбор товара
и загрузку номенклатуры магазина.

Расширение разработано агентом Claude Code по техническому заданию из папки [`tz/`](tz/TASK.md).

## Что умеет расширение

### Форма «Подбор цветов»

В форме чека РМК (`Документ.ЧекККМ.Форма.ФормаДокументаРМК`) в верхней командной панели
появляются кнопки **«Подбор цветов»**, **«+»** и **«−»**. «Подбор цветов» открывает форму
обработки `цм_ПодборЦветов` в три колонки:

- **группы** — крупные плитки с цветом и значком группы; «Все» показывает весь ассортимент;
- **товары** — плитки с картинкой из карточки номенклатуры (основная картинка, а не файл на
  диске), наименованием и ценой по виду цен чека; клик добавляет товар, повторный клик —
  +1 к количеству;
- **«Выбрано»** — набранные строки: количество (+ / − / ввод), удаление строки, сумма и итог.

Поиск — по наименованию и по штрихкоду (ввод вручную или сканером). Кнопка «Перенести в чек»
отдаёт набранное в форму РМК, и строки попадают в чек **типовым путём быстрых товаров**
(`ДобавитьВКорзинуФрагмент`): цену, НДС, продавца и скидки заполняет типовой код, строка с тем
же товаром не дублируется, а получает добавленное количество. Наборы раскладываются на
комплектующие типовым `ДобавитьВКорзину`.

Кнопки «+» и «−» в форме РМК меняют количество текущей строки чека и пересчитывают её типовым
обработчиком изменения количества.

Дальше всё типовое: оплата, запись и проведение чека, пробитие на ККТ через БПО, X- и Z-отчёты.

### Обработка «Загрузка номенклатуры»

`Обработка.цм_ЗагрузкаНоменклатуры` читает `data/nomenclature.json` и `images/` из указанного
каталога (это папка [`tz/`](tz/)) и заводит в базе:

- корневую группу магазина и 9 групп номенклатуры в порядке `order`, со значками и цветом
  плитки;
- единицы измерения (`шт`, `ветка`, `пучок`, `лист`) и вид номенклатуры для цветов;
- 75 товаров в своих группах, со штрихкодами (`РегистрСведений.ШтрихкодыНоменклатуры`);
- картинку товара — присоединённым файлом и основной картинкой карточки;
- розничные цены — типовым документом установки цен на вид цен из `meta.priceType`.

Повторный запуск ничего не дублирует: товар находится по коду и артикулу, изменившееся
обновляется. Итог загрузки — сколько создано, обновлено и пропущено по каждому виду объектов,
и список ошибок (ошибка одного товара не мешает остальным).

## Состав расширения

Префикс собственных объектов — `цм_`.

**Свои объекты:**

| Объект | Назначение |
| --- | --- |
| `Обработка.цм_ПодборЦветов` | форма подбора: плитки групп и товаров, поиск, «Выбрано», перенос в чек |
| `Обработка.цм_ЗагрузкаНоменклатуры` | загрузка `nomenclature.json` и картинок; логика — в модуле менеджера, функция `Загрузить(КаталогДанных)` |
| `ОбщийМодуль.цм_ПлиткиТоваровВызовСервера` | серверные данные для плиток: группы, товары, цены, картинки из карточек, штрихкоды — `ДанныеПлиток()` |
| `Роль.цм_ОсновнаяРоль` | права на использование и просмотр обеих обработок |

**Заимствованные объекты:**

- `Документ.ЧекККМ` с формой `ФормаДокументаРМК` — команды «Подбор цветов», «+», «−» и
  обработчик результата подбора;
- справочники `Номенклатура`, `ВидыНоменклатуры`, `УпаковкиЕдиницыИзмерения`, `СтавкиНДС`,
  `Склады` и другие, нужные форме и загрузке;
- общие картинки, определяемые типы (`Цена`, `ДенежнаяСумма…`), перечисление

## Установка

1. **Загрузить расширение в базу.** В Конфигураторе: «Конфигурация» → «Расширения
   конфигурации» → «Добавить» → у нового расширения «Конфигурация» → «Загрузить конфигурацию
   из файлов…» → каталог `src/` → «Обновить конфигурацию базы данных». Или из командной строки:

   ```
   1cv8.exe DESIGNER /F "<каталог базы>" /N "<пользователь>" /P "<пароль>" /LoadConfigFromFiles "<путь к репозиторию>\src" -Extension ЦветочнаяКасса /UpdateDBCfg
   ```

2. **Снять безопасный режим.** В режиме «Предприятие»: «Администрирование» → «Печатные формы,
   отчёты и обработки» → «Расширения» → «ЦветочнаяКасса» → снять «Безопасный режим». Без этого
   загрузка номенклатуры не прочитает файлы.
3. **Дать права.** Роль `цм_ОсновнаяРоль` — кассирам и администратору.
4. **Загрузить номенклатуру.** Открыть обработку «Загрузка номенклатуры» (например, через
   «Все функции» → «Обработки» или по навигационной ссылке
   `e1cib/app/Обработка.цм_ЗагрузкаНоменклатуры`), указать каталог данных — путь к папке `tz/`
   на сервере 1С — и нажать «Загрузить». Повторный запуск безопасен.
5. **Остатки.** Чтобы чек проводился, цветы должны быть на складе торгового зала — например,
   оприходованием излишков. Иначе РМК откажет: «недостаточно свободного остатка».

## Работа кассира

1. Открыть смену в РМК (типовая команда).
2. В форме чека нажать **«Подбор цветов»**.
3. Выбрать группу, кликать по плиткам товаров; или найти товар поиском, или отсканировать
   штрихкод.
4. Поправить количество в «Выбрано» и нажать **«Перенести в чек»**.
5. Оплатить типовой командой РМК; чек пробивается на ККТ через БПО.

## ККТ

Расширение к кассовому оборудованию не привязано: чек пробивается тем, что подключено в БПО.
При разработке касса была эмулирована — [emulkon](https://github.com/iMironRU/emulkon) 0.9.4
(драйвер для БПО и сервер эмуляции с журналом фискальных документов вне 1С). На нём пробита
смена из трёх чеков ТЗ (300, 1 050, отказ «нет бумаги» и повтор на 550; Z-отчёт 1 900), журнал
эмулятора сверен с чеками 1С построчно — без расхождений.

## Известные ограничения

- Таблица «Выбрано» в веб-клиенте при масштабе 90 % узковата: колонка «Сумма» заходит за край.
- Скидки, бонусы, возвраты и сборка букетов из компонентов не делались — по ТЗ это следующие
  задания.
